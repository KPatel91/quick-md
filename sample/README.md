# Quick MD

A fast, minimalist Markdown reader. This folder is a set of fixtures that exercise everything the renderer supports.

- [Typography](guides/typography.md) — headings, lists, quotes, emphasis
- [Code](guides/code.md) — syntax highlighting in several languages
- [Diagrams](guides/diagrams.md) — Mermaid
- [Tables and extras](guides/extras.md) — tables, task lists, footnotes, alerts
